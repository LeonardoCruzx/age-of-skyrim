# 0011. Sede da facção escolhida entre fortes/torres candidatos

- **Status:** Aceita
- **Data:** 2026-10-27
- **Origem:** Decisão do usuário

## Contexto
A facção precisa de uma base inicial numa província.

## Decisão
Fortes/torres candidatos (1–2 por província) são marcados no JSON com um bloco `seat`. Ao conquistar um candidato sem ter sede, o jogador pode fundá-la ali (registro `SEAT` no cosave). Outros mods podem adicionar candidatos.

## Consequências
- Liberdade de escolha com conteúdo curado.
- Cada candidato precisa de coordenadas para baú e mesa (ADR 0007).
