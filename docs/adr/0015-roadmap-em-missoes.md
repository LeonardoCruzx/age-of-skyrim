# 0015. Desenvolvimento em missões sequenciais

- **Status:** Aceita
- **Data:** 2026-10-27
- **Origem:** Decisão do usuário

## Contexto
O trabalho é grande e precisa avançar em passos verificáveis.

## Decisão
O roadmap (`docs/ROADMAP.md`) é quebrado em missões (M1–M28 na versão atual; a lista pode crescer, ex.: ADRs 0020 e 0031), executadas uma por vez: implementação + CI verde + docs + commit/push e, quando precisa do jogo, roteiro de teste do usuário. Toda decisão vira um ADR aqui.

## Consequências
- Progresso rastreável pelo git e pelos ADRs.
