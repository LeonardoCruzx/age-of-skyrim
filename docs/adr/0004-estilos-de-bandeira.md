# 0004. Bandeiras por estilo (heráldica), não por facção

- **Status:** Aceita
- **Data:** 2026-10-27
- **Origem:** Técnica

## Contexto
Facções criadas pelo jogador são ilimitadas, mas modelos de bandeira são finitos.

## Decisão
Existe um conjunto fechado de estilos; cada território tem bandeiras por estilo e cada facção escolhe um estilo. Trocar o dono habilita as do estilo do dono e desabilita as outras (só quando o estado muda).

## Consequências
- Novas facções não exigem novos modelos.
- Novos estilos exigem arte nova.
